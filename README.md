# Minecraft Rainbow Pickaxe Mod

Rainbow Pickaxe Mod is a Fabric Minecraft mod that adds a single Rainbow Pickaxe item with a colorful texture, Netherite-tier mining properties, and a right-click ability that grants Speed II and Night Vision. The implemented ability lasts 30 seconds and has no cooldown.

## Install

1. Install Minecraft 26.3, Java 25 or later, Fabric Loader 0.20.1 or later, and Fabric API.
2. Place the mod’s compatible JAR file in your Minecraft `mods` folder.
3. Launch Minecraft using your Fabric profile.

## Use

1. Find the Rainbow Pickaxe in the Tools creative tab.
2. Hold it in your main hand and right-click to receive Speed II and Night Vision for 30 seconds.
